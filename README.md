# KulTur

An intelligent, location-aware travel concierge for Bosnia & Herzegovina. The chatbot uses **Retrieval-Augmented Generation (RAG)** grounded in a verified cultural heritage database, enhanced by a **Random Forest preference re-ranker** and spatial corridor filtering.

---

## 💬 Features

* **Grounded AI Assistant:** Provides detailed travel suggestions based exclusively on verified historical, cultural, and natural landmarks across Bosnia & Herzegovina.
* **Personalized ML Re-Ranking:** Re-ranks suggested sites using a trained `RandomForestClassifier` based on user-selected preferences (interests, time budget, season, and region).
* **Location & Travel-Aware:** Dynamically adjusts site recommendations when a user mentions being in a specific town or having a vehicle.
* **Dual-View Dashboard:** Includes both an interactive conversational interface and an exploratory spatial map view.
